Absensi Lebih Cerdas & Cepat Dengan Wajah Anda

FACE_ABSENSII adalah solusi modern presensi kehadiran siswa menggunakan sistem kecerdasan buatan berbasis client-side face detection & recognition menggunakan Face-API.js dan database terintegrasi Supabase.

Instan & Real-time

Pencatatan kehadiran dilakukan dalam milidetik setelah wajah terdeteksi dan terverifikasi.

Koneksi PostgreSQL

Integrasi database aman langsung dengan Supabase PostgreSQL melalui proteksi environment variables.

Face-API.js Engine

Memproses pengenalan wajah langsung di browser tanpa perlu server GPU mahal di backend.

Tujuan & Manfaat Proyek

Sistem ini dirancang untuk menggantikan proses absensi manual dengan teknologi pengenalan wajah. Proyek ini bertujuan mempercepat waktu pendataan kehadiran siswa di sekolah, mengurangi manipulasi data kehadiran (titip absen), serta mempermudah staf administratif dalam mengunduh laporan rekapitulasi berkala dalam bentuk Excel/PDF secara otomatis.

"Meningkatkan akurasi kehadiran dengan integrasi biometric recognition real-time secara fleksibel, hemat biaya, dan aman."

Langkah-langkah Instalasi Lokal

Ikuti panduan berikut untuk menduplikasi dan menjalankan proyek FACE_ABSENSII di komputer lokal Anda:

1

Clone Repositori

Clone proyek ini ke folder lokal web server Anda (misal: htdocs atau directory pilihan Anda):

git clone https://github.com/[username]/sistem_absensi.git
2

Konfigurasi Environment Variables

Duplikat file .env.example menjadi .env di root direktori, lalu sesuaikan konfigurasi database Supabase PostgreSQL Anda:

DB_HOST=aws-0-ap-southeast-1.pooler.supabase.com
DB_PORT=5432
DB_USER=postgres.xxx
DB_PASS=Password_Supabase_Anda
DB_NAME=postgres
3

Jalankan Aplikasi

Aktifkan Apache & MySQL server (misal lewat XAMPP) atau jalankan menggunakan server PHP lokal di root direktori:

php -S localhost:8000

Alur Kerja Sistem (System Workflow)

Berikut adalah visualisasi alur bagaimana data wajah dipindai, dianalisis, dan dicatat sebagai kehadiran siswa:

1

Deteksi Bounding Box Wajah

Kamera webcam mendeteksi adanya objek wajah di layar secara dinamis menggunakan model Tiny Face Detector bawaan Face-API.js.

2

Pencocokan Deskriptor Biometrik

Sistem mengekstrak landmark 68 titik wajah dan menghitung kecocokan jarak Euclidean dengan dataset foto yang terdaftar di database.

3

Logging Presensi & Rekap Otomatis

Saat wajah cocok di bawah threshold (≤ 0.6), backend menyimpan data ID siswa, waktu kehadiran, dan status presensi (Tepat Waktu/Terlambat).

Panduan Mengaktifkan GitHub Pages

Setelah dokumen-dokumen di folder docs/ di-push ke repositori GitHub, aktifkan halaman web agar bisa diakses oleh publik secara online:

1

Buka Pengaturan Repositori

Masuk ke repositori GitHub kelompok Anda, lalu klik tab Settings di menu navigasi atas.

2

Masuk ke Menu Pages

Di sidebar sebelah kiri bagian bawah (di bawah menu "Code and automation"), klik menu Pages.

3

Tentukan Branch & Folder Source

Pada bagian "Build and deployment", set source menjadi Deploy from a branch. Kemudian pilih branch main (atau branch utama Anda) dan pilih direktori /docs.

4

Simpan & Verifikasi

Klik tombol Save. Tunggu sekitar 1-2 menit hingga GitHub Actions selesai memproses build halaman Anda. Tautan URL aktif halaman dokumentasi Anda akan tertera pada bagian atas menu Pages tersebut.
